# Changelog

## 0.1.4 - 2026-10-21
- Corrected the version the plugin reports, so its listings, its assets, and its built-in documentation all name the installed build.

## 0.1.3 - 2026-10-21
- Tested with WordPress 7.1.3 and WooCommerce 11.2.1, and the plugin states the exact versions it was tested with, so WordPress and WooCommerce no longer report it as untested on a current site.
- Added opt-in uninstall cleanup through the core extension policy for extension-owned report settings and transients.

## 0.1.2 - 2026-07-13

- Stream all matching orders in stable, bounded-memory CSV batches.
- Protect customer and administrator text from spreadsheet formula execution in exported files.
- Reject impossible custom calendar dates and calculate presets in the configured WordPress timezone.
- Improve report, chart, table, and control contrast across light, dark, and system admin themes.
- Flatten nested decorative report surfaces while preserving the chart as a framed reporting tool.
- Build deterministic order grid labels without MySQL-only aggregation syntax so reports and exports work in WordPress Playground SQLite.

## 0.1.1 - 2026-06-05

- Add Last year filtering, revenue review guidance, clearer trend summaries, focusable chart point tooltips, and standard report action buttons.

## 0.1.0

- Initial local development release.
